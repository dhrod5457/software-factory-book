## 선택 이유

이 제목은 책의 실제 범위를 그대로 설명한다.

- 특정 Coding Agent 제품 사용법이 아니다.
- 완전 자율 개발 조직을 약속하지 않는다.
- Agent를 개인 도구가 아니라 Software Production System 안의 Worker로 운영하는 문제를 다룬다.
- Durable Task, Verification, Recovery, Governance, Flow라는 책의 핵심을 포괄한다.

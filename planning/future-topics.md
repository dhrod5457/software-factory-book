# Future Topics

기준일: 2026-09-28

이 문서는 현재 **AI Software Factory** 책의 핵심 범위를 벗어나지만 후속 연구나 별도 책으로 발전할 수 있는 주제를 보존한다.

현재 책에서 제외한다는 의미이지 중요하지 않다는 뜻은 아니다.

---

# 1. Autonomous Product Factory

Software Engineering을 넘어:

```text
Market Signal
→ Product Discovery
→ Requirement
→ Software Factory
→ Experiment
→ Business Metric
→ Product Decision
```

까지 자동화하는 시스템.

현재 책은 Product Strategy 자동화를 핵심으로 하지 않는다.

---

# 2. Self-modifying Software Factory

Factory가 자기:

- instructions
- skills
- tools
- evaluator
- routing
- policy
- sandbox

를 자동 수정하는 구조.

연구 가치가 높지만 reward hacking / policy erosion 위험이 크므로 후속 주제로 둔다.

---

# 3. Agent OS

- process
- identity
- memory
- scheduler
- tool
- resource
- policy

를 Agent 중심 OS abstraction으로 통합하는 개념.

현재 책은 Software Delivery domain에 한정한다.

---

# 4. Agent Governance Platform

조직 전체 Agent의:

- identity
- permission
- model policy
- audit
- approval
- lifecycle
- compliance

를 통합 관리하는 platform.

Factory governance와 겹치지만 더 일반적인 enterprise agent 주제다.

---

# 5. Agent Security Platform

- Prompt Injection Defense
- Capability Broker
- Data Loss Prevention
- Tool sandbox
- Model behavior monitoring
- Runtime policy

를 독립 보안 제품/플랫폼 수준으로 다루는 주제.

현재 책에서는 Software Factory에 필요한 경계만 다룬다.

---

# 6. Agent Observability Platform

- distributed tracing
- semantic event
- model/tool spans
- cost
- eval
- replay
- fleet analytics

를 전문적으로 다루는 주제.

현재 책에서는 Task/Worker/Verification 운영에 필요한 observability까지만 다룬다.

---

# 7. Advanced Multi-Agent Organization

- dynamic team formation
- hierarchy
- debate
- negotiation
- market mechanism
- swarm
- emergent specialization

현재 책에서는 independent Task parallelism과 evaluator 정도까지만 다룬다.

---

# 8. Cross-organization Agent Federation

서로 다른 회사/조직의 Agent가:

- A2A
- delegated identity
- contract
- trust
- payment

를 통해 협업하는 미래 구조.

---

# 9. Autonomous Incident Remediation

```text
Production Signal
→ Diagnose
→ Patch
→ Verify
→ Deploy
→ Observe
```

를 사람 개입 없이 닫는 시스템.

현재 책에서는 단계별 risk-based automation까지만 다룬다.

---

# 10. Formal Verification for Agent-produced Software

- formal specification
- theorem proving
- model checking
- proof-carrying change

를 AI-generated code acceptance에 연결하는 주제.

---

# 11. AI-native Organization Design

Software Factory가 조직에 미치는 영향:

- team topology
- role
- manager span
- review ownership
- junior growth
- architecture governance

현재 책에서는 필요한 운영 변화만 다룬다.

---

# 12. Agent Labor Economics

- cost/task
- compute economics
- model pricing
- agent workforce scaling
- human vs agent allocation

을 경제학 관점으로 깊게 다루는 주제.

# 13. Developer Skill Transformation

- junior training
- expertise formation
- debugging skill
- code ownership
- cognitive offloading

장기 실증 데이터가 더 필요하다.

# 14. General-purpose Enterprise Agent Platform

Software Engineering뿐 아니라:

- HR
- finance
- support
- sales
- legal

을 포함하는 enterprise-wide Agent Platform.

현재 책의 domain은 Software Delivery다.

# 15. Agent Memory Architecture

- long-term memory

일반론.

- continual learning
